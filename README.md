# busca_rutas_largas
¿Te sale el error «la ruta es demasiado larga» al copiar archivos a un disco externo o USB? Esta herramienta preventiva analiza tus carpetas antes de respaldarlas, detecta qué archivos superan el límite de Windows y te permite abrirlos al instante con un clic en el Explorador para acortar nombres o moverlos, logrando transferencias completas.
